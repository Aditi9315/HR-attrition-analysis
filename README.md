# HR Attrition Analysis — IBM Dataset

Analyzed a 1,470-employee IBM HR dataset to identify key attrition 
drivers using Python (Pandas, Matplotlib).

## Key Findings
- Sales dept has ~21% attrition vs 14% in R&D
- Sales Reps show highest role-level attrition (~40%)
- First 2 years = highest flight risk

## Tools Used
Python | Pandas | Matplotlib | Google Colab
